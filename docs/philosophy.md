MonOSS stands for Monist Organization and Simulation System.

MonOSS is an object graph.

Its purpose is to be an extremely flexible organization and simulation software for personal use.

Everything in MonOSS is a mote.

Motes have properties. These properties could be anything (text, dates, numbers, etc.)

Relationships can exist between motes, organizing them.

The system should model reality, not files.

It should favor extensibility over convenience.

It should avoid special cases. Prioritize minimalism and elegance. The user should have the freedom to create their own organizational schema without the software pressing one on them.

Advanced automation between motes should be possible.

More detail on this system is later in the documentation.

In short, modeling and calculation with motes and relationships should be possible.
